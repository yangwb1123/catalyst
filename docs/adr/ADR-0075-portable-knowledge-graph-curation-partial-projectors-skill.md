# ADR-0075: Portable Knowledge Graph Curation Partial Projectors Skill

## Context
ADR-0065 freezes an authority-free GraphSnapshot v1 foundation and one exact ADR-0053 module/package lexical partial projector. ADR-0066 freezes a second independent request and envelope API that adds only package-scoped lexical Go test-source sets. Both implementations already derive canonical envelopes from caller-supplied exact request bytes, and both preserve PARTIAL coverage plus UNKNOWN system knowledge and freshness.

The portable package must preserve those two existing transport choices. A shared wrapper, tagged union or profile dispatcher would create a third request ABI that neither semantic ADR defines. Accepting a raw graph, golden fixture wrapper or existing envelope would likewise weaken exact request negotiation. Source distribution must not turn a pure projection into live repository capture, a detector, an authenticated route, a graph store, impact analysis or authority.

## Decision
Deliver the closed source package at `skills/knowledge-graph-curation/` with exactly two independent zero-argument projectors. `project_module_package_snapshot.py` accepts only the existing ADR-0065 eight-field canonical request; `project_go_test_source_snapshot.py` accepts only the existing ADR-0066 eight-field canonical request. Each reads stdin through explicit EOF with no trailing LF, requires `-I -B`, re-encodes the derived embedded request byte-for-byte to the supplied input and emits only the corresponding existing canonical envelope plus one LF on exit zero.

There is no wrapper, tagged union or profile dispatcher. The projectors reject cross-fed requests, raw graphs, fixture objects, envelopes, added fields, altered API or profile values and noncanonical bytes. Input is bounded at 24 MiB, decoded graph bytes at 16 MiB and output at 96 MiB. Complete output is prepared before writing; a write or flush failure may leave partial indeterminate stdout, so only exit zero with exact complete bytes is success.

Registry v30 adds only `knowledge_graph_curation_portable_projection`, canonical source references and the package manifest pin. Runtime scope arrays and existing ADR-0065/0066 registry blocks remain unchanged. Only the package checker is a shadow non-load-bearing detector; both projectors are deliberately absent from authenticated context routes and detector execution. The repository-root `.agent` adapter documents exact invocations without installing a host Skill.

The package manifest binds 45 members and has SHA-256 `c9b8397658c3bcecb474966a3efd155f0af550be4fe7319dcdbf23a63cec2008`; the manifest itself is the forty-sixth physical file. Two Schema copies, two golden copies and 26 named semantic leaves remain byte-identical to their source pins. Four lean package initializers intentionally expose only the runtime closure and are not claimed as whole source-tree parity.

A source-only fresh and legacy scaffold copies the sealed package, this decision and the portable governance test without copying Catalyst Go or Rust runtime, installing a host Skill, adding a route, persisting graph state or granting authority. This closes only the nested `knowledge-graph-curation` package item. The parent package rollout and Wave 2 multi-surface extractor, coverage/staleness, complete impact, Cost, Risk and authority work remain open.

## Consequences
Callers with an already-authored exact ADR-0065 or ADR-0066 request gain a portable deterministic process boundary and byte-for-byte golden comparison. The old APIs, profiles, Schema, golden bytes, identities, coverage partition and result markers do not change, and no new union negotiation is introduced.

The module/package output remains only a selected-module lexical subgraph. The test-source output adds lexical source sets, not test identities, cases, executions, outcomes, verification or coverage. In both profiles coverage remains PARTIAL and system/freshness remain UNKNOWN. Stable IDs are caller-declared project-scoped semantic-name identities, not authenticated global entities or rename lineage.

Package validation observes a closed file set at one time but is not a signature, trusted installer, sandbox, publisher identity or atomic check-to-use protocol. Python isolation does not authenticate or isolate the interpreter, standard library, system site, startup, host or supplied bytes.

## Validation
Run the isolated package checker, fourteen portable projector tests, ten package-integrity tests and the official Skill structural validator. Positive tests extract each exact embedded request from its matching golden, close stdin explicitly and require the exact frozen envelope plus one LF. Negative tests cover cross-feed, raw graph, fixture/envelope/wrapper/union input, field/version/profile/digest drift, canonical JSON and Base64URL errors, byte/depth/count bounds, missing EOF, hostile imports, output failures and package filesystem attacks.

Re-run the unchanged ADR-0065 and ADR-0066 Python semantic suites and Go GraphSnapshot tests. Verify the two root Schema and golden physical pins, exact packaged copies, all 26 semantic leaf copies, four lean initializers and absolute-import closure. Registry and Agent Engineering tests must preserve the existing runtime scope, package-only shadow detector, portable route absence, discipline placement and non-capability boundary.

Run the source-only fresh and legacy scaffold checks against generated trees. Copied checkers, projector tests and governance tests must pass from scrubbed environments; generated projects must contain no Catalyst Go/Rust runtime, host Skill installation, authenticated route, graph state, Impact/Cost/Risk engine or authority infrastructure.

## Limitations
This delivery consumes only caller-supplied exact request bytes. It does not inspect a repository, Git, build selection, Go source, test declarations, clock, environment, credential, process, provider, network, database, journal or graph store. It does not call the ADR-0053 producer, refresh a graph, merge profiles, repair digests or persist output.

It authenticates no caller, project, graph producer, repository, source revision, clock, host, publisher or interpreter. It creates no Evidence, Claim, Context, Grant, Approval, receipt, test result, verified edge, ChangeImpactReport, Cost, Risk, AssessmentReceipt, completion, transition, execution or effect. It cannot report complete, fresh, safe, no impact, low risk, accepted or compliant.

ADR-0065 and ADR-0066 remain the sole semantic authorities. A third profile, selected-build semantics, test execution, live capture, multi-surface coverage, authenticated provenance, durable graph, impact traversal, routing, persistence or authority requires a separately versioned contract and evidence. ADR-0075 remains Proposed packaging and source-governance only.
