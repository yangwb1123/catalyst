# ADR-0076: Portable Change Impact Cost Risk Lexical Prescan Skill

## Context
ADR-0053 freezes a caller-supplied local Go module/package lexical dependency observation. ADR-0062 freezes a pure `ImpactPreScan` that consumes one exact seven-field canonical request containing changed paths and that observation as canonical Base64URL bytes. It derives only the exact reverse local-edge closure within the supplied observation, while system impact remains UNKNOWN.

The portable package must preserve that existing wire and semantic boundary. Accepting a raw or parsed graph, golden fixture or envelope, or adding a wrapper, tagged union, mode or dispatcher would create an ABI that ADR-0062 does not define. Source distribution must not turn lexical projection into observation production, live repository or build analysis, complete impact assessment, Cost, Risk, materiality, safety, routing, persistence or authority.

## Decision
Deliver the closed source package at `skills/change-impact-cost-risk/` with one zero-argument exact-request projector. `project_local_go_package_impact_prescan.py` accepts only the existing ADR-0062 seven-field canonical request. It reads stdin through explicit EOF with no trailing LF, requires `-I -B`, re-encodes the derived envelope's embedded request byte-for-byte to the supplied input and emits only the existing canonical envelope plus one LF on exit zero.

There is no raw graph or wrapper, tagged union, profile selector, dispatcher or request authoring path. The projector rejects graph fixtures, existing envelopes, added fields, altered API or digest values, noncanonical JSON, noncanonical Base64URL and requests not explicitly closed at EOF. Input is bounded at 24 MiB, decoded graph bytes at 16 MiB and output at 48 MiB. Complete output is prepared before writing; a write or flush failure may leave partial indeterminate stdout, so only exit zero with exact complete bytes is success.

Registry v31 adds only `change_impact_cost_risk_portable_projection`, canonical source references and the package manifest pin. Runtime scope arrays and the existing ADR-0062 registry block remain unchanged. Only the package checker is a shadow non-load-bearing detector; the projector and portable Skill are deliberately absent from authenticated context routes. The repository-root `.agent` adapter documents exact invocations without installing a host Skill.

The package manifest binds 31 members and has SHA-256 `d46202beacc000c6fbdc14afb1c5996476af90d9c0e8927da6f1bf56bf354ad5`; the manifest itself is the thirty-second physical file. The Schema, golden and 15 named semantic leaves remain byte-identical to their source pins. Four lean package initializers intentionally expose only the runtime closure and are not claimed as whole source-tree parity.

A source-only fresh and legacy scaffold copies the sealed package, this decision and the portable governance test without copying Catalyst Go or Rust runtime, installing a host Skill, adding a route, persisting graph or impact state or granting authority. This closes only the nested `change-impact-cost-risk` package item. The parent rollout and Wave 2 multi-surface extractor, coverage and staleness, complete Impact, Cost, Risk, materiality, safety and authority work remain open.

## Consequences
Callers with an already-authored exact ADR-0062 request gain a portable deterministic process boundary and byte-for-byte golden comparison. The existing request and envelope APIs, Schema, golden bytes, identities, closure rules, UNKNOWN system status and result marker do not change, and no new negotiation surface is introduced.

The lexical closure is complete only within the supplied ADR-0053 observation under ADR-0062 rules. Zero reachable dependents does not mean no system impact, safe, low Cost, low Risk, immaterial or accepted. Selected build constraints, dependency availability, compile and runtime reachability, tests, deployments, schemas, APIs, events and other repository surfaces remain unavailable.

Package validation observes a closed file set at one time but is not a signature, trusted installer, sandbox, publisher identity or atomic check-to-use protocol. Python isolation excludes the script directory, `PYTHONPATH` and user site; it does not authenticate or isolate the interpreter, standard library, system site, startup, host, publisher or caller-supplied bytes.

## Validation
Run the isolated package checker, fourteen portable projector tests, ten package-integrity tests and the official Skill structural validator. Positive tests extract the exact embedded request from the golden, close stdin explicitly and require the exact frozen envelope plus one LF. Negative tests cover raw graph, fixture/envelope/wrapper/union input, field/version/digest drift, canonical JSON and Base64URL errors, 16 MiB decoded and 24 MiB stdin N/N+1 bounds, missing EOF, nonblocking writer-open stdin, hostile CWD/PYTHONPATH/import state, output bounds, short writes and package filesystem attacks.

Re-run the unchanged ADR-0062 Python semantic suite and Go `goimpactprescan` tests. Verify the root Schema and golden physical pins, exact packaged copies, all 15 semantic leaf copies, four lean initializers and anchored absolute-import closure. Registry and Agent Engineering tests must preserve the existing runtime scope, package-only shadow detector, portable route absence, discipline placement and non-capability boundary.

Run source-only fresh and legacy scaffold checks against generated trees. Copied checker, projector and governance tests must pass from scrubbed environments; generated projects must contain no Catalyst Go/Rust runtime, host Skill installation, authenticated route, graph capture, impact state, complete Impact/Cost/Risk engine or authority infrastructure.

## Limitations
This delivery consumes only caller-supplied exact request bytes. It does not inspect a repository, Git, Go source, build selection, test declarations or results, APIs, events, database schemas, deployments, ADR ownership, clock, environment, credential, process, provider, network, journal, graph store or impact store. It does not call the ADR-0053 producer, refresh a graph, repair a request or persist output.

It authenticates no caller, project, graph producer, repository, source revision, host, publisher or interpreter. It creates no Evidence, Claim, Context, Grant, Approval, GraphSnapshot, ChangeImpactReport, Cost, Risk, materiality or safety verdict, AssessmentReceipt, completion, transition, execution or effect. It cannot report complete, fresh, safe, no impact, low Cost, low Risk, accepted or compliant.

ADR-0053 and ADR-0062 remain the sole semantic authorities. Live capture, selected-build semantics, multi-surface coverage, authenticated provenance, complete impact traversal, Cost, Risk, materiality, safety, routing, persistence or runtime authority requires a separately versioned contract and evidence. ADR-0076 remains Proposed packaging and source-governance only.
